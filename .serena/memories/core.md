# Project Core
- AI Career Intelligence Platform backend. Implemented through Milestone 14 (state 2026-10-05, no active milestone): PostgreSQL schema, structured job ingestion (`/jobs/import`, fed by `../Crawl`), BM25/dense/RRF/reranking, safe SQL/search tools, LangGraph router (`/agent/query`), CV skill gap (`/cv/upload`) and CV match (`/cv/match`), M7 evaluation, skill alias merge/learning/review, resumable indexing. Per-milestone reports: `docs/milestones/`.
- Current task authority: `docs/CURRENT_MILESTONE.md` (overwritten per milestone) overrides `docs/PROJECT_SPEC.md` for that milestone. Never edit `../Crawl`.
- Source map: `app/api` FastAPI routes; `app/tools` independent SQL/search tools; `app/graph` LangGraph routing/state; `app/cv` CV PDF/extraction/skill gap/matching; `app/skills` skill taxonomy, alias learning and review; `app/jobs.py` job read service; `app/db` SQLAlchemy/session/repositories; `app/ingestion` cleaning/extraction/validation; `app/retrieval` keyword/dense/hybrid/reranking/Qdrant; `app/schemas` Pydantic API models; `scripts` maintenance CLIs (sync_skills, load_demo_jobs, index_jobs, merge/learn/review skills, check_deepseek; documented in scripts/README.md); `demo` separate Streamlit chat UI calling the API (own pyproject); `migrations` Alembic; `evaluation` benchmarks; `tests` test suite.
- `data/taxonomy/skill_aliases.json` is the single curated skill source; blocklist stays alongside it. `scripts.sync_skills` synchronizes it without jobs; `scripts.load_demo_jobs` synchronizes skills and loads 12 jobs from `data/examples/demo_jobs.json` in one transaction. `data/examples/sample_jobs.json` and `.csv` are separate import fixtures. Business persistence remains in `app/skills/taxonomy.py`.
- Roadmap and scope authority: `docs/PROJECT_SPEC.md`; implement only the user-requested milestone and do not edit the spec unless explicitly requested.
- Required implementation order: PostgreSQL/schema -> ingestion/extraction -> dense retrieval -> hybrid/reranking -> independent SQL/search tools -> LangGraph routing -> minimal CV skill gap -> evaluation/deployment.
- Keep business logic outside API routes. SQL and retrieval tools must work independently before LangGraph integration.
- Never commit secrets, API keys, CV contents, or private data. Update `.env.example` when adding environment variables.
- Chat provider details in `mem:chat_provider`. Read stack details in `mem:tech_stack`, codebase conventions in `mem:conventions`, runnable workflows in `mem:suggested_commands`, and completion gates in `mem:task_completion`.
