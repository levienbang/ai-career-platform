# Suggested Commands
- Local setup: `python3 -m venv .venv`; `source .venv/bin/activate`; `python -m pip install -e '.[dev]'` (or `uv run …`).
- Local database/app: `alembic upgrade head`; `python -m scripts.sync_skills` before real imports; `python -m scripts.load_demo_jobs` only for an isolated demo/evaluation DB; `uvicorn app.main:app --reload`.
- Production-style Compose: `docker compose up --build -d`; then `docker compose exec api alembic upgrade head`, `... python -m scripts.sync_skills` (or `... python -m scripts.load_demo_jobs` for isolated demo data), `... python -m scripts.index_jobs`.
- Dev Compose: `docker compose -f docker-compose.yml -f docker-compose.dev.yml up --build -d`; later starts omit `--build`; logs via the same files plus `logs -f api`. Rebuild after pyproject/Dockerfile/system dependency or bundled data-layout changes.
- Tests/checks: `pytest`; `ruff check .`; `ruff format --check .`. In dev Compose: `docker compose -f docker-compose.yml -f docker-compose.dev.yml exec api pytest -q`. Docker E2E: `docker compose exec -e RUN_DOCKER_E2E=1 api pytest -q tests/test_e2e_pipeline.py`.
- Indexing: `python scripts/index_jobs.py` (incremental by document_hash, needs Google key), `--payload-only` (no embedding, after skill renames), `--full` (re-embed all).
- Skill maintenance (merge/learn dry-run by default; review mutations write immediately; see scripts/README.md): `scripts/merge_skills.py [--apply]`; `scripts/learn_skill_aliases.py` (dry-run still **calls DeepSeek**, saves proposals) then `--apply --from skill_learning_proposals.json`; `scripts/review_skill_decisions.py list|approve|keep-new|revert`.
- Paid/live provider commands (ask user first): `scripts/check_deepseek.py`, `learn_skill_aliases.py`, `index_jobs.py` (non payload-only), `evaluation.evaluate_retrieval|evaluate_agent|evaluate_routing`. Offline: `python -m evaluation.evaluate_milestone7` (needs DB with only the 12 jobs from data/examples/demo_jobs.json).
- Demo UI: `cd demo && uv run streamlit run app.py` (API at `CAREER_API_URL`, default http://localhost:8000).
- Serena memory reference check: `serena memories check` from repository root.
